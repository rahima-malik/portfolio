## 🛠️ Tech Stack & Tools

This portfolio is built from scratch without any heavy frameworks:
*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, Variables), Vanilla JavaScript
*   **Design Style:** Swiss Modernism / Editorial Minimal (Dark Theme)
*   **Typography:** Google Fonts (Sora, Plus Jakarta Sans, JetBrains Mono, Instrument Serif)
*   **Deployment:** Netlify
*   **Version Control:** Git & GitHub

---

## ✨ Key Features

*   **Fully Responsive:** Optimized for Desktop, Tablet, and Mobile devices.
*   **Modern UI/UX:** Dark theme with neon accents, glassmorphism effects, and smooth scroll animations.
*   **Dynamic Typing Effect:** Custom JavaScript typing animation in the hero section.
*   **Interactive Projects Section:** Filterable project cards with hover tilt effects and direct GitHub repo links.
*   **Downloadable CV:** Easy access for recruiters to download my resume.
*   **Functional Contact Form:** Includes a custom math/captcha verification with mailto integration.
